# Панель REST — информация по сотрудникам и картам

## Как открыть

Меню **«Панель REST»** (`fa-tachometer`) или адрес
`/city/index.php/restdashboard`.

Страница показывает те же восемь показателей, что и блок «Информация по
сотрудникам и картам» старой панели, но получает данные через Artonit REST
API v2.

## Что означает каждый показатель

| Показатель | Значение |
|---|---|
| Количество пользователей | все записи `PEOPLE`, включая служебные, гостей и архив |
| Количество удалённых пользователей | сотрудники с `ACTIVE = 0` |
| Всего карт у сотрудников | карты типа сотрудника (по умолчанию 1), все статусы |
| Срок действия завершится до | активные карты, срок которых истекает до конца указанного дня |
| Срок карты закончился | активные карты с истёкшим `TIMEEND` |
| Сотрудники без карты | сотрудники, у которых нет ни одной карты (оценка по табельному номеру) |
| Количество неактивных карт | карты с `ACTIVE = 0` |
| Неправильный формат RFID | карты типа сотрудника, содержащие строчные латинские `a–f` |

## Списки

Нажмите на число — откроется список записей этого показателя. В списке есть
постраничный переход и кнопка «Обновить». Для списков сроков, RFID и
«сотрудники без карты» данные собираются обходом карт, поэтому при большом
объёме список может быть ограничен; об этом выводится предупреждение.

## Почему цифры могут отличаться от старой панели

* API не видит карты без владельца (`CARD` без строки `PEOPLE`);
* «Сотрудники без карты» считается по уникальным `TABNUM`, при дублях номеров
  значение приблизительное;
* «Срок действия завершится до» учитывает только активные карты и включает
  последний день горизонта — это исправление старого расчёта;
* у старой панели и REST API могут различаться часовые пояса, если
  `api_timezone` не настроен.

## Что делать при ошибке

1. Нажмите «Повторить».
2. Проверьте, запущен ли Artonit REST API (`http://localhost:5056`).
3. Проверьте `modules/restdashboard/config/restdashboard.php` (`api.base_url`,
   `api.token`).
4. Посмотрите `application/logs` — там полный текст ошибки.

Если API недоступен, но ранее данные уже загружались, страница покажет
резервную копию с пометкой «Данные устарели».
