версия 1.5.0
23.11.2026
[+]
Добавлен метод PUT /api/v2/organizations/{divcode}/accessnames — сохранение набора
категорий доступа указанной организации (таблица SS_ACCESSORG). Тело запроса
{"accessnames":[...]}: набор заменяется целиком — лишние связи удаляются, недостающие
добавляются, пустой массив очищает набор, дубликаты игнорируются. Ответ — сохранённый
массив id_accessname по возрастанию. Несуществующая категория — 422 ACCESSNAME_NOT_FOUND,
отсутствие таблицы SS_ACCESSORG — 409 SS_ACCESSORG_UNAVAILABLE. Метод изменяющий:
требуется роль администратора. Обновлены docs/ORGANIZATIONS_API_v2.md и дымовой тест.

версия 1.3.0
23.11.2026
[+]
Добавлены команды управления категориями доступа /api/v2/Access:
POST (создание), DELETE /{id_accessname} (удаление), GET /GetList (постраничный
список с фильтром AccessName) и GET /GetPeople (список tabnum сотрудников
с указанной категорией по таблице SS_ACCESSUSER).
Идентификатор категории — ID_ACCESSNAME (таблица ACCESSNAME).
Удаление категории удаляет её правила доступа (ACCESS); связи с сотрудниками
(SS_ACCESSUSER) удаляются каскадно. Системную категорию id_accessname=1
удалить нельзя. Добавлены описание docs/ACCESS_API_v2.md и дымовой тест
docs/smoke-tests/access.ps1.

версия 1.2.0
22.11.2026
[+]
Добавлены команды управления организациями /api/v2/organizations:
POST (создание), GET /{divcode} (чтение), GET (постраничный список с фильтрами
parent, name и сортировкой), PUT (полная замена name/parent/flag), PATCH (частичное
изменение), DELETE (удаление без дочерних организаций и активных сотрудников).
Код организации во всех маршрутах, параметрах, полях JSON и кодах ошибок обозначается divcode
(колонка ORGANIZATION.DIVCODE, от division).
Ответы 4xx/5xx возвращаются в едином формате { "error", "message", "details": [...] }.
Изменяющие команды требуют токен с ролью администратора: /login?username=ADMIN&pasword=333
выдаёт роль admin, остальные логины — роль user (только чтение).
Подготовлены миграции БД в docs/migrations: уникальный индекс UNQ_ORGANIZATION_DIVCODE
и необязательная колонка ORGANIZATION.DATE_CREATE для неизменяемой даты создания.
Добавлен дымовой тест docs/smoke-tests/organizations.ps1.

Версия 1.0.2
25.04.2025 г.
[+]
добавлены методы IdentifierTypeConroller get - для получения списка типов идентификаторов.

Identifier GET - получить список идентификаторов с фильтром по номеру идентификатора.
Если фильр не указан, то будет выбирать все идентификаторы (с разбиением на страницы).

Identifier GET - присвоение идентификатора указанному person.
При обработке выполняется валидация:
- номер должен быть строго  HEX заглавными (большими) буквами, 
- длина - строго 8 символов.
